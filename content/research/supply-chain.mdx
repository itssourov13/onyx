## The workstation is part of the supply chain

Dependency risk does not start in CI. Local package managers, lockfiles, scripts and developer credentials all participate in the path from source to artifact.

## Evidence model

A practical chain connects the declared dependency graph to the resolved graph, build environment, artifact digest and deployment record.

## Regression target

The strongest useful test is repeatability: can the same source revision produce an artifact whose inputs and digest can be explained later?
