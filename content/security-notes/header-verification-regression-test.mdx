## Headers are contracts

Security headers should be treated as regression-test inputs. A source configuration is not enough if the deployed response differs.

## Contract surface

Test content security policy, framing restrictions, MIME sniffing protection, referrer behavior and browser capability restrictions.

## Deployment check

Record the expected response contract and compare it with the live response. Keep development-only exceptions out of the production baseline.
