## Boundary map

Map browser origins, frames, storage, navigation and DOM-controlled state before selecting a test case.

## Disposable fixtures

Use synthetic identities and isolated state for regression cases. A security test should be able to run repeatedly without changing unrelated application state.

## Review checklist

- origin and frame relationships are explicit
- persistence is intentionally scoped
- navigation and messaging are treated as interfaces
- reset is deterministic
