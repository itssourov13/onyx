## Isolation is a feature

Security regression tests should not require real user accounts or durable application state. Synthetic fixtures make failure reproducible and cleanup predictable.

## Pattern

```text
create fixture → exercise boundary → capture evidence → reset
```

Keep fixture storage separate from application storage. If a test fails, its evidence should still be useful without leaving a changed state behind.
