## Privacy is a property, not a badge

Transport encryption protects data in transit, but it does not automatically provide anonymity, unlinkability or freedom from metadata collection. Those are separate properties with different threat models.

## Design observations

A privacy-oriented transport layer should make collection points explicit. Headers, logs, identifiers, retry behavior and error messages can all create data exhaust even when the payload is encrypted.

## A small contract

```text
transport security → confidentiality + integrity
privacy architecture → minimization + purpose limitation + controlled retention
```

The demo uses this distinction deliberately: it presents privacy-oriented terminology without claiming that the site itself provides anonymity or zero logging.

## Verification

For an implementation, verify both source configuration and deployed behavior. A transport contract is useful only when the browser and server actually enforce it.
