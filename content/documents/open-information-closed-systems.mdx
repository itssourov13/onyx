## Private systems still have public consequences

A system can be privately operated while affecting public users, infrastructure or norms. Conversely, a public interface can contain private information that should not be exposed merely because the interface is reachable.

## The design tension

Good information architecture distinguishes access from secrecy. A document may be public while its operational metadata is private; a system may be closed while publishing a transparent security contract.

## Editorial rule

The archive therefore labels its records clearly. Fictional material is marked as demo content, while technical references are separated from claims about the fictional system itself.
